## Default Permission

AniHy 네이티브 탭바의 기본 명령 모두 허용

#### This default permission set includes the following:

- `allow-set-tabs`
- `allow-select-tab`
- `allow-get-insets`
- `allow-watch-tab-selected`
- `allow-watch-insets`
